# GLOSSARY

## LifeOS

**Versão:** 1.0

**Status:** Documento Fundacional

---

# Objetivo

Este documento define a linguagem oficial do domínio do LifeOS.

Todos os documentos, implementações e agentes de IA devem utilizar exatamente os termos aqui definidos.

Não criar sinônimos.

Não alterar nomenclaturas.

A consistência da linguagem é parte da arquitetura.

---

# Produto

## LifeOS

Plataforma de desenvolvimento humano baseada em dados, gamificação e evolução contínua.

Não utilizar:

- Sistema
- Aplicativo
- Software

Sempre utilizar:

**LifeOS**

---

# Usuário

Pessoa que utiliza o LifeOS.

No domínio poderá ser chamado de:

**Player**

Representa o protagonista da própria jornada.

---

# Character

Representação digital do Player.

Contém:

- atributos
- nível
- experiência
- conquistas
- títulos
- estatísticas

---

# Avatar

Representação visual do Character.

Não possui regras de negócio.

---

# XP (Experience)

Valor acumulado através de ações reais.

XP nunca representa tempo.

XP representa progresso.

---

# Nível

Representa a evolução acumulada do Character.

É calculado a partir da experiência.

---

# Atributo

Representa uma dimensão permanente do desenvolvimento humano.

Atributos oficiais:

- COR
- LIN
- TRA
- TER
- LOG
- MUS

---

# Skill

Competência específica desenvolvida pelo Player.

Exemplos:

- Corrida
- Leitura
- Meditação
- Programação

---

# Quest

Objetivo definido para determinado período.

Pode ser:

- diária
- semanal
- mensal
- ciclo

---

# Achievement

Conquista permanente.

Obtida após cumprir determinadas condições.

Nunca é removida.

---

# Badge

Elemento visual associado a uma Achievement.

---

# Rank

Classificação do Character dentro de determinado atributo.

---

# Title

Título conquistado pelo Player.

Exemplo:

- Aprendiz
- Especialista
- Mestre

---

# Streak

Quantidade de dias consecutivos mantendo determinada atividade.

---

# Mission

Conjunto de Quests relacionadas.

---

# Reward

Recompensa concedida ao Player.

Pode conter:

- XP
- Badge
- Achievement
- Título

---

# Health

Domínio responsável pelos indicadores biológicos.

---

# Workout

Domínio responsável pelos exercícios.

---

# Reading

Domínio responsável pela leitura.

---

# Therapy

Domínio responsável pelas sessões terapêuticas.

---

# Habit

Comportamento repetitivo monitorado pelo sistema.

---

# Analytics

Conjunto de cálculos responsáveis por gerar indicadores.

---

# Insight

Conclusão produzida a partir dos dados.

Sempre baseada em evidências.

Nunca em opinião.

---

# AI Mentor

Assistente inteligente do LifeOS.

Sua função é:

- orientar
- explicar
- recomendar
- incentivar

Nunca tomar decisões pelo usuário.

---

# Dashboard

Tela principal do LifeOS.

Exibe a Character Sheet.

---

# Character Sheet

Tela principal inspirada em MMORPGs.

Representa o estado atual do Player.

---

# Engine

Conjunto de regras responsáveis por determinado comportamento.

Exemplos:

- XP Engine
- Analytics Engine
- AI Engine

---

# Module

Conjunto funcional do sistema.

Exemplos:

- Health Module
- Workout Module
- Reading Module

---

# Entity

Objeto principal do domínio.

Possui identidade própria.

---

# Value Object

Objeto imutável utilizado pelo domínio.

Não possui identidade.

---

# Repository

Camada responsável pela persistência.

Nunca contém regra de negócio.

---

# Service

Camada responsável pelas regras de negócio.

---

# Use Case

Fluxo de execução de uma funcionalidade específica.

---

# Event

Representa um acontecimento relevante do domínio.

Pode ser utilizado para comunicação entre módulos.

---

# Aggregate

Conjunto de entidades relacionadas tratadas como uma única unidade.

---

# DTO

Objeto utilizado para transporte de dados entre camadas.

---

# Domain

Camada responsável por representar o negócio.

Nunca depende de tecnologia.

---

# Infrastructure

Camada responsável por recursos externos.

Exemplos:

- banco
- e-mail
- arquivos
- backup

---

# Interface

Forma de interação com o usuário.

Exemplos:

- Streamlit
- API
- CLI

---

# Sprint

Unidade oficial de desenvolvimento.

Cada Sprint possui:

- objetivo
- entregáveis
- critérios de aceite

---

# Release

Conjunto de Sprints disponibilizadas ao usuário.

---

# Definição Oficial

Os termos descritos neste documento constituem a linguagem oficial do LifeOS.

Nenhuma documentação ou implementação deverá utilizar terminologia diferente para representar os mesmos conceitos.
