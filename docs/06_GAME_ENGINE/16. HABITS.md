# 1. Objetivo

Este documento define a arquitetura oficial do Sistema de Hábitos (Habit System) da Game Engine do LifeOS.

O Habit System é responsável por transformar ações repetidas do cotidiano em progresso permanente do Character.

Enquanto Missões e Quests direcionam objetivos específicos, os Hábitos representam os comportamentos recorrentes que sustentam a evolução de longo prazo.

O sistema de Hábitos constitui um dos pilares centrais da Game Engine.

---

# 2. Filosofia

A verdadeira evolução não acontece em grandes eventos.

Ela acontece através da repetição de pequenas ações.

No LifeOS:

- um treino isolado possui valor;
- cem treinos transformam o Character.

O sistema incentiva consistência, não intensidade.

---

# 3. Princípios

Todo o sistema deverá seguir os seguintes princípios.

## Consistência

Pequenas ações frequentes possuem maior valor.

---

## Simplicidade

Todo hábito deve ser facilmente compreendido.

---

## Progressão

Os hábitos fortalecem a evolução contínua.

---

## Personalização

Cada usuário constrói seus próprios hábitos.

---

## Mensurabilidade

Todo hábito deve possuir critérios objetivos de conclusão.

---

# 4. Arquitetura

Fluxo oficial:

```text
Habit

↓

Execution

↓

Game Event

↓

Habit System

↓

Character

↓

Persistence
```

Os hábitos geram eventos para toda a Game Engine.

---

# 5. Conceito

Um Hábito representa uma ação recorrente.

Exemplos:

- ler diariamente;
- correr;
- estudar;
- meditar;
- beber água;
- dormir cedo;
- escrever no diário.

O hábito existe independentemente das Quests.

---

# 6. Estrutura

Cada Hábito deverá possuir:

```text
ID

Nome

Descrição

Categoria

Periodicidade

Objetivo

Status

Data de Criação

Data da Última Execução
```

Todo hábito possui identidade única.

---

# 20. Declaração Final

O Sistema de Hábitos constitui um dos pilares fundamentais da Game Engine do LifeOS.

Ele transforma pequenas ações repetidas em progresso permanente, conectando diretamente a rotina do usuário aos sistemas de Experiência, Atributos, Skills, Inteligências, Quests e Achievements.

Projetado para incentivar consistência acima de intensidade, o Habit System materializa a filosofia central do LifeOS: grandes transformações são resultado da repetição disciplinada de pequenas ações realizadas diariamente, permitindo que a evolução do Character reflita fielmente a evolução da pessoa real.
