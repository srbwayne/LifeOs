---

# 1. Objetivo

Este documento define a arquitetura oficial do Sistema de Atributos (Attributes System) da Game Engine do LifeOS.

Os atributos representam as características permanentes do Character.

Enquanto o XP representa progresso e o Nível representa maturidade, os atributos representam **quem o personagem se tornou** ao longo da jornada.

Toda evolução pessoal influencia direta ou indiretamente algum atributo.

---

# 2. Filosofia

O objetivo dos atributos não é criar números arbitrários.

Cada atributo deve representar uma competência real desenvolvida pelo usuário.

O Character não melhora porque derrotou monstros.

Ele melhora porque:

- treinou;
- estudou;
- dormiu melhor;
- criou hábitos;
- manteve disciplina;
- evoluiu como pessoa.

---

# 3. Princípios

Todo o sistema deverá seguir os seguintes princípios.

## Persistência

Atributos representam evolução permanente.

---

## Progressão Lenta

Atributos evoluem lentamente.

Pequenas ações repetidas produzem grandes mudanças.

---

## Baseado em Evidências

Todo aumento de atributo deve ser consequência de atividades reais.

---

## Balanceamento

Nenhum atributo deve crescer indefinidamente sem esforço correspondente.

---

## Especialização

Cada usuário constrói um Character único.

---

# 4. Arquitetura

Fluxo oficial:

```text
Real Activity

↓

Game Event

↓

Attribute System

↓

Character

↓

Persistence
```

Toda alteração passa pelo Attribute System.

---

# 5. Conceito

Um atributo representa uma característica permanente do Character.

Exemplos:

- disciplina;
- foco;
- energia;
- criatividade;
- resiliência.

Os atributos nunca representam tarefas.

Eles representam capacidades.

---

# 6. Estrutura

Cada atributo possui:

```text
ID

Nome

Descrição

Valor Atual

Valor Máximo

Histórico

Data Última Evolução
```

Toda alteração deve ser rastreável.

---

# 7. Atributos Oficiais

O LifeOS define inicialmente os seguintes atributos.

```text
Disciplina

Foco

Energia

Resiliência

Criatividade

Consistência

Sabedoria

Autoconhecimento
```

Novos atributos poderão ser adicionados futuramente.

---

# 8. Disciplina

Representa a capacidade de executar ações independentemente da motivação.

Exemplos que aumentam Disciplina:

- manter hábitos;
- cumprir rotina;
- finalizar tarefas;
- concluir missões.

---

# 9. Foco

Representa a capacidade de manter atenção em uma atividade.

Exemplos:

- leitura;
- estudo;
- trabalho profundo;
- meditação.

---

# 10. Energia

Representa a capacidade física e mental disponível.

Exemplos:

- qualidade do sono;
- exercícios;
- descanso;
- alimentação saudável.

A Energia não representa HP.

Ela representa vitalidade.

---

# 11. Resiliência

Representa a capacidade de continuar evoluindo diante de dificuldades.

Exemplos:

- manter sequência após falhas;
- superar períodos difíceis;
- concluir desafios longos.

---

# 12. Criatividade

Representa a capacidade de produzir novas ideias.

Exemplos:

- escrita;
- desenho;
- música;
- programação;
- projetos pessoais.

---

# 13. Consistência

Representa estabilidade ao longo do tempo.

É influenciada por:

- streaks;
- frequência;
- regularidade;
- repetição.

Consistência vale mais do que intensidade isolada.

---

# 14. Sabedoria

Representa conhecimento aplicado.

Exemplos:

- livros concluídos;
- cursos;
- prática;
- reflexão.

Sabedoria não é apenas informação acumulada.

---

# 15. Autoconhecimento

Representa a compreensão do próprio comportamento.

Exemplos:

- terapia;
- journaling;
- reflexão;
- registro emocional.

Esse atributo diferencia o LifeOS de RPGs tradicionais.

---

# 16. Evolução

Fluxo:

```text
Game Event

↓

Attribute Rules

↓

Attribute Gain

↓

Character Update
```

Nem todo evento altera atributos.

Cada evento possui regras específicas.

---

# 17. Balanceamento

Cada atributo possui velocidade própria de evolução.

Exemplo conceitual:

```text
Disciplina

++

```

```text
Sabedoria

+

```

```text
Criatividade

+++

```

O balanceamento será definido pela Game Engine.

---

# 18. Integração

Os atributos influenciam outros sistemas.

Exemplos:

```text
Attributes

↓

Skills

↓

Achievements

↓

Quests

↓

AI Recommendations
```

A IA poderá utilizar os atributos para personalizar desafios.

---

# 19. Evolução Futura

O sistema suporta futuras expansões.

Exemplos:

- atributos compostos;
- bônus temporários;
- talentos;
- especializações;
- modificadores;
- afinidades;
- sinergias.

A arquitetura permanece compatível.

---

# 20. Declaração Final

O Sistema de Atributos representa a evolução permanente do Character dentro do LifeOS.

Diferentemente de RPGs tradicionais, seus atributos não são distribuídos manualmente nem aumentam por decisões arbitrárias.

Eles refletem diretamente os comportamentos, hábitos e conquistas reais do usuário, transformando desenvolvimento pessoal em crescimento mensurável dentro da Game Engine.

Essa abordagem torna os atributos um dos pilares centrais da identidade do Character e da proposta do LifeOS como um sistema operacional para evolução humana.
